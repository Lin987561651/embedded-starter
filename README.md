# embedded-starter

> 从点亮第一颗 LED 开始的嵌入式实践记录

## 为什么会有这个仓库

不是为了凑 star，是为了回答一个问题：**我到底做出来过什么。**

每一份笔记都对应一个能跑的东西，每一个项目都写清接线、代码和踩过的坑。半年后回头看，这就是最硬的证据。

## 怎么跑起来

用 [PlatformIO](https://platformio.org)（推荐，比 Arduino IDE 更适合长期学）：

```bash
pio run              # 只编译
pio run -t upload    # 编译并烧录到板子
pio device monitor   # 看串口输出
```

用 Arduino IDE 也行：选 `Arduino Uno` → 选端口 → 上传。

## 每个项目的记录格式

后续每个项目文件夹里都会写清楚四件事：

1. **要解决的问题** —— 一句话
2. **接线** —— 哪根线接哪个脚
3. **代码** —— 能直接编译
4. **踩坑** —— 卡住的地方和怎么解决的

第 4 条最值钱。
